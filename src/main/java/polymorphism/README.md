# STEP Session 8 — Polymorphism

This package contains 10 Java solutions based on the uploaded Week 8 Category C PDFs.

- `class_problems/`: 5 practice problems
- `assigment_problems/`: 5 assignment problems

Each program is standalone. Compile and run one file at a time, for example:

```powershell
javac PaymentSystemFeeCalculation.java
java PaymentSystemFeeCalculation
```

The solutions model different behavior using interfaces and implementing classes. The main processing loop uses a common type, while each implementation provides its own calculation.

Note: The question statements' sample input formats are followed as closely as practical. The exam grader and library due-date problems parse quoted input records as described in their PDFs.
