# STEP Session 9 — Abstraction and Interfaces

This package is based on the uploaded Category C practice and coding-assignment PDFs.

- `class_problems/` contains the five practice problems.
- `assigment_problems/` contains the five assignment problems.
- Each Java program is standalone and formatted with consistent indentation and line breaks.

## Compile and run

Open a terminal in the folder containing the Java file. For example:

```powershell
javac GardenPlotAreaReport.java
java GardenPlotAreaReport
```

Use the class name of the file you want to run. The solutions use abstract classes and interfaces to keep shared behavior in one place and specialized behavior in the relevant class.
