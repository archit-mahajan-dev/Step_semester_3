# STEP Week 10 — Java Arrays Practice

This package contains the five Week 10 coding assignments supplied in the PDFs.

## Structure

```text
arrays/
├── class_problems/
└── assigment_problems/
    ├── BusiestBusRow.java
    ├── ClassAttendanceTracker.java
    ├── DutyRosterRotation.java
    ├── ExamScoreBandCounter.java
    └── SecondBestScore.java
```

The uploaded Week 10 PDFs contained five assignment problems. They have therefore been placed in `assigment_problems`; no class-practice problems were added.

## Compile and run

From the directory containing a Java file, compile and run it with:

```bash
javac ExamScoreBandCounter.java
java ExamScoreBandCounter
```

Replace `ExamScoreBandCounter` with the class name you want to run.

Each file includes a sample input format, example, expected output, and complexity notes in a comment.
